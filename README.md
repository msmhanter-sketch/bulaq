# Butaq (Бутақ) — Қазақ тілді бағдарламалау тілі

**Butaq** — қазақ тілінде жазуға негізделген, статикалық типтелетін және таза x86-64 ассемблер кодына компиляцияланатын бағдарламалау тілі. Тіл ешқандай C++ немесе Go виртуалды машиналарынсыз тікелей дербес машиналық кодқа компиляцияланады.

```butaq
"Сәлем, Әлем!" жазу

# Уақыт өлшеу
бастау уақыт() болсын
ұйықтау(0.5)
аяқтау уақыт() болсын

өткен аяқтау бастау алу болсын
"Өткен уақыт (с):" жазу
өткен жазу
```

---

## 🚀 Басты Ерекшеліктері

- **Қазақ тілді синтаксис** — барлық операторлар, циклдар және типтер қазақ тілінде
- **Статикалық типтеу** — айнымалылар мен параметрлер компиляция кезінде тексеріледі
- **Толық LSP қолдауы** — VS Code, Neovim, Helix редакторларында автотолтыру мен диагностика
- **Бай қате хабарлары** — нақты жол/баған, контекст және шешім ұсынысымен
- **Кірістірілген Stdlib** — уақыт, JSON, крипто, ағын, жүйе функциялары
- **NASM + LLVM екі бэкенд** — жергілікті немесе LLVM арқылы компиляция
- **ARC жад басқару** — автоматты санаққа негізделген Reference Counting
- **Әлсіз сілтемелер** — циклді тізбектер үшін `әлсіз` кілт сөзі

---

## 🛠️ Қажетті құралдар

1. **Go 1.18+** — компилятор өзін жинақтау үшін
2. **NASM** — `.asm` файлын объектілік файлға айналдыру үшін
3. **GCC (MinGW, Windows-та)** — байланыстырушы

## 📂 Жоба Құрылымы

```
├── codegen/           x86-64 NASM және LLVM IR генераторлары
├── lexer/             Лексикалық талдаушы
├── parser/            Синтаксистік талдаушы + AST
├── typechecker/       Статикалық тип тексеру + Linter
├── interpreter/       WASM үшін баяу орындаушы
├── runtime/           runtime.c — кірістірілген функциялар C реализациясы
├── docs/              Құжаттама (EN/KK/RU)
│   ├── stdlib_kk.md   Стандартты кітапхана (қазақша)
│   ├── stdlib_en.md   Standard library (English)
│   └── tutorial_kk.md Оқулық
├── examples/          .btq мысал бағдарламалары
├── editors/           LSP конфигурациялары
└── main.go            CLI кіру нүктесі
```

## 💻 Тілдің синтаксисі

### Айнымалылар

```butaq
аты "Арман" болсын
жасы 25 болсын
бағасы 99.9 болсын
оқушы_ма ақиқат болсын
```

### Шарт және цикл

```butaq
егер жасы үлкен_тең 18 {
    "Ересек" жазу
} әйтпесе {
    "Кәмелетке толмаған" жазу
}

санауыш 0 болсын
әзірше санауыш кіші 5 {
    санауыш жазу
    санауыш санауыш қосу 1 болсын
}
```

### Функциялар

```butaq
функция факториал(n) {
    егер n кіші_тең 1 {
        1 қайтару
    }
    n факториал(n алу 1) көбейту қайтару
}

факториал(10) жазу   # → 3628800
```

### Құрылымдар және Әдістер

```butaq
құрылым Шеңбер {
    радиус САН
}

әдіс ауданы Шеңбер(өзі) {
    3.14159 өзі.радиус көбейту өзі.радиус көбейту қайтару
}

c жасау Шеңбер болсын
c.радиус 5.0 болсын
c ауданы() жазу   # → 78.5398
```

### Уақыт функциялары

```butaq
# Unix timestamp
t уақыт() болсын

# Пішімделген уақыт
күн уақыт_мәтіні("%Y-%m-%d") болсын
күн жазу   # → "2026-05-20"

# Күту
ұйықтау(1.5)   # 1.5 секунд
```

### JSON

```butaq
адам жсон_жаңа() болсын
жсон_мәтін_қосу(адам, "аты", "Арман")
жсон_сан_қосу(адам, "жасы", 30.0)

жол жсон_жазу(адам) болсын
жол жазу
```

### Крипто

```butaq
хэш ша256("Butaq") болсын
хэш жазу

жол б64_кодтау("Сәлем Әлем") болсын
жол жазу
```

## 🔨 Пайдалану

### Компиляторды жинақтау

```bash
go build -o butaq.exe
```

### Бағдарламаны компиляциялау және іске қосу

```bash
# Компиляция (NASM бэкенд, Windows)
.\butaq.exe examples/hello.btq

# Бірден іске қосу
.\butaq.exe -r examples/test_time.btq

# LLVM бэкенд (clang қажет)
.\butaq.exe --llvm -r examples/test_loop.btq
```

### Код пішімдеу

```bash
.\butaq.exe fmt examples/myprogram.btq
```

### LSP сервері (VS Code, Neovim)

```bash
.\butaq.exe lsp
```

## 🎯 Тілдің уникалдылығы

Butaq — **дүние жүзіндегі алғашқы қазақ тілді компиляторлы бағдарламалау тілі**:

- Синтаксис қазақтың табиғи SOV сөйлем құрылымына сай
- Кирилл жазуымен толық жұмыс жасайды (Unicode-compliant)
- Орысша, ағылшынша және қазақша анықтамалар
- 100% нативті компиляция — интерпретатор немесе JVM жоқ
