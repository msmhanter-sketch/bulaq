# Bulaq Бағдарламалау Тілі

Bulaq (Бұлақ) - қазақ тіліндегі бірегей, стекке негізделген (stack-based) бағдарламалау тілі.
Ол Python немесе C сияқты тілдердің көшірмесі емес. Қазақ тілінің сөйлем құрылымы (Бастауыш-Толықтауыш-Баяндауыш, SOV) стекке негізделген тілдердің (Forth сияқты) постфиксті (postfix) логикасына өте жақсы сәйкес келеді.

Сондықтан `жазу(5 + 10)` орнына Bulaq тілінде `5 10 қосу жазу` деп жазамыз.

## Негізгі ұғымдар

Барлық деректер стекке салынады. Операциялар стектегі соңғы мәндерді алып, нәтижесін қайтадан стекке салады.

### Математикалық операциялар
* `қосу` (+)
* `алу` (-)
* `көбейту` (*)
* `бөлу` (/)
* `қалдық` (%)

Мысалы:
```
10 5 алу жазу  # 5 шығарады (10 - 5)
```

### Стек операциялары
* `көшіру` (dup) - стектің төбесіндегі мәнді көшіреді
* `тастау` (drop) - стектің төбесіндегі мәнді өшіреді
* `ауыстыру` (swap) - стектің жоғарғы екі мәнінің орнын ауыстырады
* `астыңғы` (over) - стектің екінші мәнін төбесіне көшіреді

### Енгізу-шығару
* `жазу` (print) - стек төбесіндегі мәнді экранға шығарады
* `оқу` (read) - пайдаланушыдан жол оқып, стекке салады

### Логикалық операциялар
* `тең` (==)
* `үлкен` (>)
* `кіші` (<)

### Шартты операторлар (If/Else)
```
[шарт] егер
    ...
әйтпесе
    ...
бітті
```
Мысалы:
```
10 5 үлкен егер
    "Он бестен үлкен" жазу
бітті
```

### Циклдер (While)
```
басы
    [шарт]
әзірше
    ...
бітті
```
Мысалы: 1-ден 5-ке дейін санау
```
1
басы
    көшіру 6 кіші
әзірше
    көшіру жазу
    1 қосу
бітті
тастау
```

### Функциялар (Қосалқы бағдарламалар)
Жаңа сөздерді (функцияларды) `дегеніміз` және `бітті` арқылы анықтаймыз:
```
квадрат дегеніміз
    көшіру көбейту
бітті

5 квадрат жазу  # 25 шығарады
```
