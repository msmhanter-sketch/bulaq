# Bulaq (.bu) Тілі

Bulaq - бұл қазақ тіліндегі толыққанды, компиляцияланатын (compiled) бағдарламалау тілі.
Bulaq компиляторы сіздің `.bu` файлдарыңызды оқып, оларды дербес (standalone) орындалатын файлдарға (executable binaries) айналдырады.

Бұл Python немесе басқа тілдерге тәуелді емес, тікелей операциялық жүйеде жұмыс істейтін бағдарламалар жазуға мүмкіндік береді.

## Синтаксис

* `жазу "мәтін"` - экранға шығару
* `айнымалы x = 5` - айнымалыны жариялау
* `егер x > 0 { ... } әйтпесе { ... }` - шартты оператор
* `әзірше x < 10 { ... }` - цикл (while)

## Қолдану

```bash
# Компиляторды құрастыру
go build -o bulaq

# .bu файлын компиляциялау
./bulaq build hello.bu

# Бұл hello (немесе hello.exe) файлын жасайды.
./hello
```
