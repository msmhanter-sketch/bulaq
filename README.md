# Butaq (Бутақ) — Қазақ тілді бағдарламалау тілі

**Butaq** — қазақ тілінде жазуға негізделген, статикалық типтелетін және таза x86-64 ассемблер (nasm) кодына компиляцияланатын бағдарламалау тілі. Тіл ешқандай C++ немесе Go виртуалды машиналарынсыз (runtime-сыз) тікелей дербес машиналық кодқа компиляцияланады.

---

## 🚀 Басты Ерекшеліктері

- **Қазақ тілді синтаксис**: Барлық операторлар, циклдар және типтер қазақ тілінде жазылады.
- **Статикалық типтеу**: Айнымалылар мен өрістер статикалық түрде тексеріледі.
- **Құрылымдар (Structures)**: Пайдаланушы анықтайтын типтер және олардың кез келген деңгейдегі терең жинақталуы (nested structs).
- **Массивтер мен Тізімдер**: Статикалық жады бөлу арқылы құрылымдар мен негізгі типтердің жиындарын басқару.
- **Әдістер және ООП (Object-Oriented Programming)**: Құрылымдарға арналған әдістерді (`өзі` сілтемесі арқылы) жариялау және шақыру.
- **Модульдік жүйе (`енгізу`)**: Басқа файлдарды модуль ретінде қосу мүмкіндігі.
- **Тереңдетілген қауіпсіздік тексерістері (Runtime Safety)**:
  - Массив шекарасынан шығуды бақылау (Array Out of Bounds check).
  - Бос сілтемелерге жүгінуді бақылау (Null Pointer check).
  - Нөлге бөлудің алдын алу (Division by Zero check).

## 🛠️ Қажетті құралдар

Бағдарламаларды жинақтап, іске қосу үшін келесі құралдар қажет:
1. **Go 1.18+** (компилятордың өзін жинақтау үшін).
2. **NASM** (ассемблерлік `.asm` файлын объектілік файлға айналдыру үшін).
3. **GCC (MinGW Windows-та)** (объектілік файлды C стандартты кітапханасымен байланыстырып, соңғы дербес `.exe` жасау үшін).

## 📂 Жоба Құрылымы

```text
├── codegen/          # x86-64 NASM ассемблер кодын генерациялаушы пакет
├── lexer/            # Бастапқы кодты токендерге бөлшектеуші (Lexical analyzer)
├── parser/           # Синтаксистік талдаушы және AST құрушы пакет
├── typechecker/      # Статикалық типтерді тексеруші және қателерді анықтаушы пакет
├── examples/         # Мысалдар мен тест файлдары (.btq кеңейтілімінде)
├── go.mod            # Go модуль файлы
├── main.go           # Компилятордың кіру нүктесі (Main CLI)
└── README.md         # Осы құжат
```

## 💻 Бағдарлама мысалы (`examples/test_complex.btq`)

```butaq
"--- Күрделі құрылымдар тесті ---" жазу

құрылым Адам {
    аты МӘТІН
    жасы САН
}

# Адамдар тізімін жасаймыз
массив [Адам жасау, Адам жасау] болсын

# Массивтегі бірінші адамның атын және жасын қоямыз
массив 0 тізім_алу .аты "Әли" болсын
массив 0 тізім_алу .жасы 25 болсын

# Оқимыз және тексереміз
аты1 массив 0 тізім_алу .аты болсын
жасы1 массив 0 тізім_алу .жасы болсын

"Бірінші адам:" жазу
аты1 жазу
жасы1 жазу

"--- Тест аяқталды ---" жазу
```

## 🔨 Қолдану Нұсқаулығы

1. **Компиляторды жинақтау**:
   ```bash
   go build -o butaq.exe main.go
   ```

2. **Butaq бағдарламасын компиляциялау**:
   ```bash
   # Мысалы, test_complex.btq файлын компиляциялау
   .\butaq.exe examples/test_complex.btq
   ```
   *Нәтижесінде таза машиналық кодта жазылған `test_complex.exe` атты дербес бағдарлама жасалады.*

3. **Бағдарламаны іске қосу**:
   ```bash
   .\test_complex.exe
   ```
