## Мәтін функциялары

### `мәтін_ұзындығы(мәтін)` → САН
Мәтіннің ұзындығын байт санымен қайтарады.

```butaq
ұзындық мәтін_ұзындығы("Сәлем") болсын
ұзындық жазу   # → 10 (UTF-8 байттар)
```

### `таңба(код)` → МӘТІН
Unicode кодынан бір таңба жасайды.

```butaq
әріп таңба(1040) болсын   # → "А"
әріп жазу
```

## Математика функциялары

### `кездейсоқ()` → САН
0.0 мен 1.0 аралығындағы кездейсоқ сан қайтарады.

```butaq
сан кездейсоқ() болсын
сан жазу   # → 0.374821...
```

### `түбір(сан)` → САН
Санның квадрат түбірін қайтарады.

```butaq
нәтиже түбір(16.0) болсын
нәтиже жазу   # → 4.0
```

### `дәреже(негіз, дәреже)` → САН
`негіз ^ дәреже` есептейді.

```butaq
нәтиже дәреже(2.0, 10.0) болсын
нәтиже жазу   # → 1024.0
```

### `синус(сан)` → САН
Синус мәнін радианмен есептейді.

```butaq
нәтиже синус(3.14159) болсын
нәтиже жазу   # → ~0.0
```

### `косинус(сан)` → САН
Косинус мәнін радианмен есептейді.

```butaq
нәтиже косинус(0.0) болсын
нәтиже жазу   # → 1.0
```

## Тип түрлендіру

### `мәтін(сан)` → МӘТІН
Санды мәтінге айналдырады.

```butaq
жол мәтін(42.0) болсын
жол жазу   # → "42"
```

### `сан(мәтін)` → САН
Мәтінді санға айналдырады. Жарамсыз мәтін үшін 0 қайтарады.

```butaq
n сан("3.14") болсын
n жазу   # → 3.14
```

### `бүтін(сан)` → БҮТІН
Санды бүтін санға кесіп тастайды.

```butaq
b бүтін(3.99) болсын
b жазу   # → 3
```

## Уақыт функциялары

### `уақыт()` → САН
Ағымдағы Unix уақытын секундпен (double) қайтарады.

```butaq
t уақыт() болсын
t жазу   # → 1748000000.0
```

### `уақыт_мәтіні(пішім)` → МӘТІН
Ағымдағы уақытты `strftime` пішімімен мәтін ретінде қайтарады.

| Пішім | Сипаттама | Мысал |
|-------|-----------|-------|
| `%Y`  | 4 цифрлы жыл | `2026` |
| `%m`  | Ай (01–12) | `05` |
| `%d`  | Күн (01–31) | `20` |
| `%H`  | Сағат 24-форматта | `21` |
| `%M`  | Минут | `09` |
| `%S`  | Секунд | `45` |

```butaq
күн уақыт_мәтіні("%Y-%m-%d") болсын
күн жазу   # → "2026-05-20"

уақыт уақыт_мәтіні("%H:%M:%S") болсын
уақыт жазу   # → "21:09:45"
```

### `ұйықтау(секунд)` → (жоқ)
Бағдарламаны берілген секунд уақытқа тоқтатады. Бөлшек секундтар қолдауы бар.

```butaq
"Жүктелуде..." жазу
ұйықтау(1.5)   # 1.5 секунд күту
"Дайын!" жазу
```

## Жүйелік функциялар

### `жүйе(команда)` → САН
Жүйелік команданы іске қосады, шығыс кодын қайтарады.

```butaq
код жүйе("mkdir жаңа_қалта") болсын
```

### `жүйе_шығысы(команда)` → МӘТІН
Жүйелік команданы іске қосады және оның стандартты шығысын мәтін ретінде қайтарады.

```butaq
нәтиже жүйе_шығысы("echo Сәлем") болсын
нәтиже жазу   # → "Сәлем"
```

### `аргумент_саны()` → САН
Командалық жолдағы аргументтер санын қайтарады.

```butaq
n аргумент_саны() болсын
n жазу
```

### `аргумент(индекс)` → МӘТІН
`индекс` нөмірлі командалық жол аргументін қайтарады. Индекс 0-ден басталады.

```butaq
файл_аты аргумент(0) болсын
файл_аты жазу
```

## JSON функциялары

### `жсон_оқу(мәтін)` → ЖСОН
JSON мәтінін объектіге айналдырады.

```butaq
деректер жсон_оқу("{\"аты\": \"Арман\", \"жасы\": 25}") болсын
```

### `жсон_жазу(объект)` → МӘТІН
JSON объектісін мәтінге айналдырады.

```butaq
жол жсон_жазу(деректер) болсын
жол жазу
```

### `жсон_сан_алу(объект, кілт)` → САН
JSON объектісінен сандық мәнді оқиды.

```butaq
жасы жсон_сан_алу(деректер, "жасы") болсын
жасы жазу   # → 25
```

### `жсон_мәтін_алу(объект, кілт)` → МӘТІН
JSON объектісінен мәтіндік мәнді оқиды.

```butaq
аты жсон_мәтін_алу(деректер, "аты") болсын
аты жазу   # → "Арман"
```

### `жсон_логика_алу(объект, кілт)` → АҚИҚАТ
JSON объектісінен логикалық мәнді оқиды.

### `жсон_нысан_алу(объект, кілт)` → ЖСОН
JSON объектісінен кірістірілген объектіні оқиды.

### `жсон_тізім_алу(объект, кілт)` → ЖСОН
JSON объектісінен тізімді оқиды.

### `жсон_тізім_өлшемі(тізім)` → САН
JSON тізімінің элемент санын қайтарады.

### `жсон_тізім_элементі(тізім, индекс)` → ЖСОН
JSON тізімінен индекс бойынша элементті алады.

### `жсон_жаңа()` → ЖСОН
Жаңа бос JSON объектісін жасайды.

### `жсон_сан_қосу(объект, кілт, мән)`
JSON объектісіне сандық мән қосады.

### `жсон_мәтін_қосу(объект, кілт, мән)`
JSON объектісіне мәтіндік мән қосады.

### `жсон_логика_қосу(объект, кілт, мән)`
JSON объектісіне логикалық мән қосады.

### Толық JSON мысал

```butaq
# JSON жасау
адам жсон_жаңа() болсын
жсон_мәтін_қосу(адам, "аты", "Арман")
жсон_сан_қосу(адам, "жасы", 30.0)
жсон_логика_қосу(адам, "белсенді", ақиқат)

# Сериализациялау
жол жсон_жазу(адам) болсын
жол жазу   # → {"аты":"Арман","жасы":30,"белсенді":true}
```

## Крипто функциялары

### `мд5(мәтін)` → МӘТІН
MD5 хэш жасайды (32 он алтылық таңба).

```butaq
хэш мд5("Сәлем") болсын
хэш жазу
```

### `ша256(мәтін)` → МӘТІН
SHA-256 хэш жасайды (64 он алтылық таңба).

```butaq
хэш ша256("Butaq") болсын
хэш жазу
```

### `б64_кодтау(мәтін)` → МӘТІН
Base64 форматына кодтайды.

```butaq
жол б64_кодтау("Сәлем Әлем") болсын
жол жазу
```

### `б64_декодтау(мәтін)` → МӘТІН
Base64 форматынан шифрлауды алады.

```butaq
түпнұсқа б64_декодтау(жол) болсын
түпнұсқа жазу
```

## Ағын функциялары

### `ұшыру(функция)` — ключевое слово
Жаңа параллель ағын іске қосады.

```butaq
функция жұмыс() {
    "Параллель ағын жұмыс жасауда" жазу
}

ағын ұшыру жұмыс болсын
ағын_күту(ағын)
```

### `ағын_күту(ағын)` → САН
Ағын аяқталуын күтеді.

## Файл функциялары

### `файл_бар_ма(жол)` → САН
Файлдың бар-жоғын тексереді. 1 = бар, 0 = жоқ.

```butaq
бар_ма файл_бар_ма("config.json") болсын
егер бар_ма тең 1 {
    "Файл табылды" жазу
}
```

### `файл_жою(жол)` → САН
Файлды жояды. 0 = сәтті, 0-ден өзгеше = қате.

```butaq
нәтиже файл_жою("temp.txt") болсын
```

## Кіріс/Шығыс

### `жазу` — команда
Мәнді экранға шығарып, жол ауыстырады. Барлық типтерге жұмыс жасайды.

```butaq
"Сәлем!" жазу
42 жазу
3.14 жазу
ақиқат жазу
```

### `енгізу()` → МӘТІН
Пайдаланушыдан мәтін оқиды (Enter-ге дейін).

```butaq
"Атыңызды енгізіңіз: " жазу
аты енгізу() болсын
"Сәлем, " жазу
аты жазу
```
