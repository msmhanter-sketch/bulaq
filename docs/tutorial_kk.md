# Butaq Тілінде Бағдарламалау Түсіндірмесі (Tutorial)

Butaq — бұл қазақ тілінің синтаксисі мен SOV (Бастауыш-Баяндауыш-Баяндауыш соңында) құрылымына негізделген заманауи бағдарламалау тілі.

---

## 1. Сәлем, Әлем!

Butaq-тағы алғашқы бағдарламаңыз:
```butaq
"Сәлем, Әлем!" жазу
```

Мұнда:
- `"Сәлем, Әлем!"` — басып шығарылатын мәтін.
- `жазу` — экранға шығару командасы (баяндауыш сөйлем соңында).

---

## 2. Айнымалылар және Типтер

Айнымалыларды жариялау үшін `болсын` кілт сөзі қолданылады:
```butaq
жас 25 болсын
аты "Әлихан" болсын
бағасы 99.9 болсын
оқушы_ма ақиқат болсын
```

Типтер автоматты түрде анықталады:
- `жас` — `БҮТІН` (int64)
- `аты` — `МӘТІН` (string)
- `бағасы` — `САН` (double)
- `оқушы_ма` — `АҚИҚАТ` (bool)

---

## 3. Шартты операторлар (егер / әйтпесе)

```butaq
жас 18 болсын

егер жас үлкен_тең 18 {
    "Сіз ересексіз!" жазу
} әйтпесе {
    "Сіз баласыз!" жазу
}
```

---

## 4. Циклдер (әзірше)

```butaq
санауыш 1 болсын

әзірше санауыш кіші_тең 5 {
    санауыш жазу
    санауыш санауыш қосу 1 болсын
}
```

---

## 5. Функциялар

Функцияларды жариялау үшін `функция` және `қайтару` сөздері қолданылады:
```butaq
функция қосу_екі(сан1, сан2) {
    сан1 сан2 қосу қайтару
}

нәтиже қосу_екі(10, 20) болсын
нәтиже жазу
```

---

## 6. Құрылымдар (құрылымдар және әлсіз сілтемелер)

```butaq
құрылым Адам {
    аты МӘТІН
    әлсіз дос Адам
}

әли жасау Адам болсын
әли.аты "Әли" болсын

асан жасау Адам болсын
асан.аты "Асан" болсын

# Циклді сілтеме жасау (әлсіз сілтеменің арқасында жад тазарады)
әли.дос асан болсын
асан.дос әли болсын
```
