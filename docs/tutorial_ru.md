# Руководство по языку Butaq (Tutorial)

Butaq — это современный статически типизированный язык программирования, использующий казахский синтаксис и структуру предложений SOV (Subject-Object-Verb / Подлежащее-Дополнение-Сказуемое). Глагол (действие) всегда находится в конце выражения.

---

## 1. Привет, Мир!

Ваша первая программа на Butaq:
```butaq
"Привет, Мир!" жазу
```

Где:
- `"Привет, Мир!"` — строка для вывода.
- `жазу` — команда вывода (глагол в конце предложения).

---

## 2. Переменные и Типы

Для создания переменных используется ключевое слово `болсын`:
```butaq
жас 25 болсын
аты "Алихан" болсын
бағасы 99.9 болсын
оқушы_ма ақиқат болсын
```

Типы выводятся автоматически:
- `жас` (возраст) — `БҮТІН` (int64)
- `аты` (имя) — `МӘТІН` (string)
- `бағасы` (цена) — `САН` (double)
- `оқушы_ма` (ученик ли) — `АҚИҚАТ` (bool)

---

## 3. Условные операторы (егер / әйтпесе)

```butaq
жас 18 болсын

егер жас үлкен_тең 18 {
    "Вы совершеннолетний!" жазу
} әйтпесе {
    "Вы несовершеннолетний!" жазу
}
```

---

## 4. Циклы (әзірше)

```butaq
санауыш 1 болсын

әзірше санауыш кіші_тең 5 {
    санауыш жазу
    санауыш санауыш қосу 1 болсын
}
```

---

## 5. Функции

Функции определяются с помощью `функция` и `қайтару` (возврат):
```butaq
функция қосу_екі(сан1, san2) {
    сан1 san2 қосу қайтару
}

нәтиже қосу_екі(10, 20) болсын
нәтиже жазу
```

---

## 6. Структуры и Слабые Ссылки (`әлсіз`)

Для предотвращения циклических зависимостей и утечек памяти используйте слабые ссылки (`әлсіз`):
```butaq
құрылым Адам {
    аты МӘТІН
    әлсіз дос Адам
}

әли жасау Адам болсын
әли.аты "Али" болсын

асан жасау Адам болсын
асан.аты "Асан" болсын

# Циклическая ссылка (благодаря әлсіз память освободится автоматически)
әли.дос асан болсын
асан.дос әли болсын
```
