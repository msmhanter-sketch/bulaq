# VS Code Extension for Butaq

This extension provides syntax highlighting and language configuration for the **Butaq (Бутақ)** programming language.

## How to Install Locally

1. Copy the `butaq-vscode` directory to your VS Code extensions folder:
   - **Windows**: `%USERPROFILE%\.vscode\extensions\`
   - **macOS/Linux**: `~/.vscode/extensions/`

   For example, in Windows PowerShell:
   ```powershell
   Copy-Item -Recurse -Force .vscode\extensions\butaq %USERPROFILE%\.vscode\extensions\butaq-vscode
   ```

2. Restart or reload your Visual Studio Code.
3. Open any file with `.btq` extension. You will see beautiful syntax highlighting for all Butaq keywords!
